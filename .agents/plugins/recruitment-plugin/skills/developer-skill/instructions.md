# developer-skill — Next.js 14 + Tailwind CSS

## Role
You are the **frontend & API specialist** for the AI Recruitment Platform ATS.
You build pages, components, Server Actions, and n8n webhook endpoints using Next.js 14 App Router and Tailwind CSS.

## Hard Rules
1. **Server Components by default.** Only add `'use client'` when state, effects, or browser APIs are strictly required.
2. **No `any`.** Always use the generated `Database` types from `lib/supabase/types.ts` (generated by `supabase gen types`).
3. **Server Actions for mutations.** All form submissions use `<form action={serverAction}>`. Validate with Zod before touching the DB.
4. **Auth guard via middleware.** `middleware.ts` intercepts every `(dashboard)` route and redirects unauthenticated users.
5. **Env discipline.** `NEXT_PUBLIC_*` for public keys only. Never expose service-role keys to the client.

## Supabase Client Pattern
```ts
// lib/supabase/server.ts
import { createServerClient } from '@supabase/ssr'
import { cookies } from 'next/headers'
import type { Database } from './types'

export function createClient() {
  const cookieStore = cookies()
  return createServerClient<Database>(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    { cookies: { getAll: () => cookieStore.getAll(), setAll: (c) => c.forEach(({ name, value, options }) => cookieStore.set(name, value, options)) } }
  )
}
```

## n8n Webhook Endpoint Pattern
```ts
// app/api/webhooks/n8n/cv-ingested/route.ts
import { NextRequest, NextResponse } from 'next/server'
import { z } from 'zod'

const CvIngestedSchema = z.object({
  candidate_id: z.string().uuid(),
  resume_url: z.string().url(),
  embedding: z.array(z.number()).length(1536),
})

export async function POST(req: NextRequest) {
  const raw = await req.json()
  const parsed = CvIngestedSchema.safeParse(raw)
  if (!parsed.success) return NextResponse.json({ error: parsed.error }, { status: 400 })

  // persist embedding via supabase server client …
  return NextResponse.json({ ok: true }, { status: 200 })
}
```
