**Semantic ranking query example:**
```sql
SELECT
  c.id,
  c.full_name,
  c.email,
  1 - (c.embedding <=> j.embedding) AS similarity_score
FROM candidates c
CROSS JOIN jobs j
WHERE j.id = '<job-uuid>'
  AND c.embedding_status = 'ready'
ORDER BY similarity_score DESC
LIMIT 20;
```
